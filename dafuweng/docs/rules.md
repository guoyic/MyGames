# MVP 规则

## 胜利

- 淘汰模式：只剩一名未破产玩家时立即获胜。
- 限回合模式：默认第 30 回合结束后按总资产排名。
- 总资产 = 现金 + 已购地产价格。

## 回合

1. 当前玩家掷骰。
2. 棋子逐格移动。
3. 经过起点获得工资。
4. 触发落点事件。
5. 若需要购买地产，玩家选择购买或跳过。
6. 结束回合并切换到下一名未破产玩家。

## 地产

- 无主地产可以购买。
- 踩到其他玩家地产时支付租金。
- 踩到自己的地产无事发生。
- 破产玩家的地产释放为无主。

## 破产

- 玩家现金小于 0 时破产。
- 破产后跳过其回合。
- 其拥有地产恢复无主。
